# QK-only and V-only CST at width 2048

English | [日本語](lm-qk-v-partial-2048-20261118.ja.md)

Train two new arms on an RTX 4090 for 4,882 updates at seed 17. In all
four blocks, QK-only uses CST for Q and K at c48 each (786,432 Atoms in
total). V-only uses CST for V at c64 (524,288 Atoms in total).
All other projections use Dense. Retain the byte-matched original weights
and biases for the complementary QKV rows. Verify the CST initial Atom
hashes against the corresponding sites in the full-QKV control.

Use the archived, verified Dense and full-QKV (48, 48, 64) seed-17 arms from
the [width-2048 study](lm-qkv-down-2048-20261118.md) as controls. Reuse the
exact native extension, model, frozen TinyStories splits, batch order, FP32
radius decoder, GPU initializer and optimizer schedule. Before training,
verify Y, dX and the four raw Atom gradients with the independent oracle
on the first Q or V projection, and audit the first q update at all
replaced sites.

Report development CE, story-disjoint confirmation CE, median synchronized
full update time after update 10 and peak PyTorch allocated and reserved
memory. This one-seed study compares placements at the per-role budgets
from full QKV. The QK-only and V-only arms use different total Atom counts.

## Reproduction

Use the width-2048 study's source snapshot and SM89 extension directory
(TORCH_EXTENSIONS_DIR). PILOT_SUMMARY is that study's completed summary.

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
python scripts/run_lm_qk_v_partial_2048.py --reference-run "$REFERENCE_RUN" \
  --pilot-summary "$PILOT_SUMMARY" --source "$SNAPSHOT" \
  --merged-manifest "$MERGED_MANIFEST" --output "$OUTPUT"
~~~

Resume with --resume, the same inputs, and the same output directory.
