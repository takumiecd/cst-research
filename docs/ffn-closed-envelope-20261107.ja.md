# 両端で合流する境界のFFN短期比較

[English（正本）](ffn-closed-envelope-20261107.md) | 日本語

Atom下限やAttention置換ではなく、境界形状を調べる探索的な追試です。
完了・停止済みの従来campaignとは分けます。

N256、pre-LN4ブロック、FFN4N、CST8射影、`A=ceil(c*sqrt(d_in*d_out))`のc8、
seed17、context128、batch2/accumulation4、FP32/TF32off、AdamW(.9,.95)、decay0、
global clip1、通常peak LR3e-4、全Atom・outer peak LR4.8e-3を固定します。
LRとデータ順の予定horizonは20Mトークンのまま、各学習は976更新・999,424トークンで
止めます。既存のhash固定済みTinyStories・tokenizer・story分離DEVを使い、
confirmation splitを短期選択に使いません。

予定する新規条件は従来q1、新境界q0、新境界q1です。新境界は
`b=clamp(1-(a/a_max)^2,0,1)`、`L=.5+49.5*b^4`、`U=.5+49.5*b`です。
a_max1、Polar活動度更新、タスク勾配での半径detachを維持します。
各条件を同じ目標二次モーメント（up std.02、down std.02/sqrt8）に再初期化し、
誤差とclippingを残します。異なる半径写像で物理振幅を同一には固定しません。

実行前の確認で、従来q1のup射影は有界振幅探索で目標に届きませんでした。
学習せず拒否を記録し、未調整の代替値には切り替えません。新境界q0・q1は
実際の8射影すべてがCPUで0.5%以内に初期化できました。GPU・学習結果はまだありません。
学習する各条件は、独立積分、native両方向の全Atom VJP、制御勾配でのoptimizer状態・復元、
実4ブロックのタスク更新・復元を先に確認します。

監査済みR12のDense・従来q0/all16の曲線を再利用し、学習を再実行しません。
保存されたstock対wrapper比較は、共通train・勾配・LR53点とDEV6点の差がゼロです。
データ・モデル・schedule・seed・初期化報告・source境界を照合して重ねます。
再利用した時間は過去の観測で、新規の同一jobでの速度比較ではありません。

初期、更新1–5、以後20更新ごとと最終976で、現在の振幅bin別に半径・qの平均/p10/p90・
件数・境界・振幅を保存します。bin所属は時点ごとに変わります。
binは[0,.001)、[.001,.01)、[.01,.03)、[.03,.1)、[.1,.3)、[.3,.6)、[.6,1]です。
空binは欠測として扱い、ゼロにしません。8射影を個別に残し、統合時は件数で重み付けします。
従来q0には途中のbin別履歴がないため、保存済みの全体履歴と終点のみ表示し、補いません。

診断は同期した更新時間の外で行います。完全更新時間とallocated/reservedのpeakを記録しますが、
診断込みwall時間・別jobの過去との比較は探索的な観測です。checkpoint・source原本とhashを
保全します。この短期比較を見てから形状や期間の追試を選び、LR・容量・3seedの自動探索はしません。
