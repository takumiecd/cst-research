# Polar：確定した関係と内部座標の設計

[English (canonical)](polar-relations-20261108.md) | 日本語

これは関係の整理であり、新しいパラメータ化の採用やLM学習の結果ではありません。
現在のFFN実験で使う、分離積・L1正規化された**cell-mass**演算が対象です。
他のCSTカーネルでは正規化の契約が異なる場合があります。
数式上の恒等式、観測結果、学習に与える設計仮説を区別します。

その後の設計判断では、質量としての振幅aを保ち、tauで制御する半径境界の中のqを
独立に学習する方針を選びました。5節のエネルギー振幅の写像は未選択の分析候補です。
[実装方針と保全の記録](worktree-cleanup-20261108.ja.md)を参照してください。

## 1. 振幅が実際に表しているもの

振幅を含まない入出力の因子を使い、1 Atomを次のように書きます。

\[
W_j=a_jK_j,\qquad K_j=u_j(r_j,\mu_{o,j})v_j(r_j,\mu_{i,j})^T,
\qquad \mathbf1^Tu_j=\mathbf1^Tv_j=1.
\]

このとき次は恒等式です。

\[
\sum_{o,i}(W_j)_{oi}=a_j,\qquad
\|W_j\|_F^2=a_j^2\|u_j\|_2^2\|v_j\|_2^2
=\frac{a_j^2}{n_{o,j}^{\mathrm{eff}}n_{i,j}^{\mathrm{eff}}},
\quad n^{\mathrm{eff}}(u)=\frac1{\|u\|_2^2}.
\]

非負で総和1の因子なら、有効セル数は1以上、サイト数以下です。
これは有効な**セル数であり、Atom数ではありません**。現在の振幅は重み行列の
符号付き総和であり、一定の行列ノルムやタスク上の重要度ではありません。
有効セル数は半径だけでなく、離散格子に対する中心の位相にも依存します。
したがって半径だけではAtomのノルムは決まりません。通常は広い因子ほど多くのセルへ
質量を分配しますが、適応窓の分岐や異なるprofileをまたぐ大域的な単調性は仮定しません。

層全体のエネルギーには、重なりと打ち消しも入ります。

\[
\|\textstyle\sum_jW_j\|_F^2=\sum_j\|W_j\|_F^2+
2\sum_{j<k}a_ja_k\langle u_j,u_k\rangle\langle v_j,v_k\rangle.
\]

1 Atomのノルムを正しく測れても、それだけでタスクへの有用性は決まりません。
データと他のAtomにも依存します。

## 2. 勾配の結びつきと限界

行列への損失勾配を \(G=\partial\mathcal L/\partial W\) とすると、微分可能な分岐で、
形状の導関数が有限なら、

\[
g_a=\langle G,K\rangle_F,\qquad
g_r=a\langle G,\partial_rK\rangle_F,\qquad
g_{\mu}=a\langle G,\partial_{\mu}K\rangle_F.
\]

振幅が厳密に0なら、半径と中心への損失勾配は0ですが、振幅勾配は残り得ます。
Gと形状の導関数が同じなら、小さい振幅は幾何パラメータへの勾配を小さくします。
ただしそれら自体も形状で変わるので、実際の勾配の大きさは振幅だけでは予測できません。
狭く格子に揃ったAtomでは、中心への感度自体が非常に小さくなる場合もあります。
中心の更新が小さいことは、有用な最適点へ到達した証拠にはなりません。

内部パラメータzと物理パラメータ \(\theta=\Phi(z)\) の関係は、

\[
g_z=J_\Phi^Tg_\theta.
\]

内部変数の共有は、物理パラメータの更新をどう結びつけるかを選ぶことです。
小さい、制約なしの**通常のSGD**のステップに限れば、
\(\Delta\theta\simeq-\eta J_\Phi J_\Phi^Tg_\theta\) です。
Adamの状態、座標ごとの前処理、射影があれば更新は変わります。
全物理パラメータのタスク勾配が0なら、滑らかな変数変換だけでは非ゼロの勾配は作れません。
変数を共有して振幅勾配で中心を動かすことはできますが、それは誘導された更新であり、
タスクがどの中心方向を望むかの証拠ではありません。
また滑らかな写像で4個未満のスカラーから、独立した4方向 \((a,r,\mu_o,\mu_i)\)
すべてを局所的に張ることはできません。

## 3. 現在のPolarが既に表している関係

現在の環状座標では、\(\rho=\sqrt{s^2+t^2}\in[1,2]\) として、

\[
a=a_{\max}s/\rho,\qquad q=(\rho^2-1)/3,\qquad
r=L(a)^{1-q}U(a)^q.
\]

微分可能な内部点では、

\[
\partial_qr=r\log(U/L),\qquad
g_s=g_a\partial_sa+g_r\partial_sr,
\quad g_t=g_a\partial_ta+g_r\partial_tr.
\]

半径微分には、振幅に依存する境界の微分とqの微分が両方入ります。
L=Uなら、qを動かしても半径は変わりません。
射影・clamp境界では微分の規約を明示する必要があり、内部点の式だけでは
実装全体の契約は決まりません。
s/rho=cos(theta)と書けばa=a_max cos(theta)でもあるため、a=±a_maxでは
この角度方向に対する振幅の感度が0になります。展開式が綺麗でも、Jacobianが
消える方向は残り得ます。この代数的な事実だけでは、学習済みAtomがその端点で
止まっているとは言えません。

[完全な連鎖律を使った同条件FFN比較](ffn-polar-radius-gradient-20261108-results.ja.md)では、
半径項がs/tの半径方向まで届くことを確認しました。最終平均半径はdetach側2.058に対し
live側1.623で、両方とも初期0.975からは広がりました。
DEV CEは3.42404と3.42239で、学習曲線は大部分が重なります。
最適な半径則や一貫した精度改善の証拠ではありません。
detach側でもCartesian Adamと射影によってqは動きました。
生の半径方向勾配が0であることと、半径方向の更新が止まることは同じではありません。

## 4. まだ仮説である関係

| 関係の案 | 現時点の位置づけ |
| --- | --- |
| \(a\to0\Rightarrow r\to r_{\max}\) | 探索を促す事前設計。損失やcell-mass正規化からは必然ではない。 |
| 大きい \(\lvert a\rvert\Rightarrow r\to r_{\min}\) | 集中を促す事前設計。有用なAtomが広い場合もあり得る。 |
| \(\|\Delta\mu\|\to0\Rightarrow r\to r_{\min}\) | 未検証。小振幅、平坦な微分、小さいLR、optimizer状態でも更新は小さくなる。 |
| 中心が大きく動くなら半径を広げる | 制御則の候補であり、カーネルの確定した性質ではない。 |
| 絶対的な中心位置で振幅・半径が決まる | 普遍的な法則は未確認。格子上の位相とタスク依存の相関を分ける必要がある。 |

観測された移動量 \(\Delta\mu\) はoptimizerのステップや履歴に依存します。
現在の内部変数から展開する静的写像だけでは参照できず、追加状態か明示的な更新則が必要です。
保存するParameterが別々であることも、学習後の統計的独立を意味しません。

## 5. 内部パラメータの意味を整理する候補

まず振幅、半径の選択、2つの中心座標を別々に操作できる4次元の基準写像を残します。
変数の共有はこの基準に対して評価し、式の美しさだけで中心の方向を制限しません。

もう一つの候補は、ノルムの恒等式から直接得られます。
符号付きの**エネルギー振幅** \(b=a\|K(r,\mu)\|_F\) を定義すると、Kが非ゼロなら、

\[
\mu=G(\xi),\qquad r=R(b,q),\qquad
a=\frac{b}{\|K(r,\mu)\|_F},\qquad
W=b\frac{K(r,\mu)}{\|K(r,\mu)\|_F}.
\]

これなら \(\|W\|_F=|b|\) となり、bが1 Atomの大きさ、qと中心が形状を担当します。
因子のノルムは \(\|K\|_F=\|u\|_2\|v\|_2\) で計算でき、密な行列は不要です。
bを固定した幾何パラメータの導関数はWに直交するため、一次の変化ではFrobenius
エネルギーを変えません。これは正規化の微分からの帰結であり、学習の成功実績ではありません。

**採用済みの置き換えではなく、候補です。** 振幅0で幾何勾配が消える問題やAtom間の
重なりは残ります。振幅に制約がなければ座標変換ですが、現在の振幅上限や境界があると
実現できる集合を変える可能性があります。\(|a|\le a_{\max}\) を保つには
\(|b|\le a_{\max}\|K\|_F\) が必要です。従来の \(L(a),U(a)\) も維持すると
陰的な方程式になり得ます。境界のaをbへ置き換えるのは新しい事前設計であり、
代数的な同値変換ではありません。内部写像の飽和や分岐境界の微分契約も必要です。
速度・学習上の利点は未検証です。

したがって次の分析対象は、有用な相関が**質量としての振幅と半径**の間にあるのか、
それとも**エネルギー振幅・形状・タスク勾配**の間にあるのかです。
物理的な初期値を揃え、両方の振幅、中心Jacobianのノルム、有効セル数、Atomの重なりを
見るのがよいと考えます。広く実験する前に、必要な方向を保ち、optimizer上の更新を
どう結びつける写像なのかを説明できる形にします。
