# FP32 radius decoding for TinyStories QKV at width 2048

English | [日本語](lm-qkv-2048-20261117.ja.md)

This study replaces Q, K and V in each of four transformer blocks. Compare
all Dense with QKV c64 and c128, using seeds 17, 23 and 42. The three arms
have identical ordinary initial tensors outside the replaced projections
within each seed. Train for 4,882 updates of 1,024 targets on the previous
TinyStories GPT-2 token data, with frozen batch order seed 905. Use width
2048, eight heads, context 128, and FFN expansion four as in the width study.

| Arm | Atoms per square projection | Atoms / Dense weights |
| --- | ---: | ---: |
| Dense | — | — |
| QKV c64 | 131,072 | 3.125% |
| QKV c128 | 262,144 | 6.25% |

Use the width study's selected width-2048 ordinary AdamW reference learning
rate 0.0001 in all arms. Keep the previous QKV amplitude and radius-fraction
reference rates of 0.0096, the 19,531-update schedule, clipping, and the
initialization with the exponential lower envelope. Use the rational lower
envelope and the research FP32 decoder during training and evaluation. The
radius range is [0.5, 512], q starts at zero, and tau changes from 0.03 to
0.003 over 1,536 updates. Save resumable checkpoints at 976, 2441 and 4882.

Qualify both candidate counts before the nine training runs. In seed 17,
compare a full projection's output, dX and all four Atom gradient fields to
the independent CPU FP64 factor reference, including modified broad-support
and endpoint rows. Check the actual first optimizer step on a separate
model copy covering all 12 QKV projections. Record the first and terminal
q update for every trained QKV arm. Before each arm, collect expired
optimizer state and record pre-arm allocated GPU memory.

The primary value is paired CE on the 8,192-target development set, with
story-disjoint 32,768-target confirmation CE and development top-1 as
secondary values. Report each seed separately. Measure synchronized eager full optimizer steps after update 10
and PyTorch allocator peaks. Use the cyclic arm order Dense/c64/c128,
c64/c128/Dense, c128/Dense/c64 in seed order 17, 23, 42.

## Reproduction

Use the [previous comparison](lm-fp32-seed-replication-20261117.md) frozen
source and data procedure. Set REFERENCE_RUN to the retained
lm-rational-projection-20261116-02 archive with its source. Overlay the
torchcst QKV patch relative to 6703a18a55cd949564be8a0ceca1ca1b813f7fc5 on
the earlier FP32 snapshot. Supply the combined source manifest, build
the exact native extension with the previous build procedure and
TORCH_CUDA_ARCH_LIST=8.9, and run on the RTX 4090.

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
export TORCH_EXTENSIONS_DIR="$EXTENSIONS"
python scripts/run_lm_qkv_2048.py --reference-run "$REFERENCE_RUN" \
  --source "$SNAPSHOT" --merged-manifest "$MERGED_MANIFEST" --output "$OUTPUT"
~~~

Resume the same run directory with the same inputs and the additional
flag --resume. The study entry records its evidence root.
