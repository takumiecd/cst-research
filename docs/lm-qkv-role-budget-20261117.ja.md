# 幅2048 QKV の固定予算での割り当て比較

[English](lm-qkv-role-budget-20261117.md) | 日本語

追加 Atom をどの射影に割り当てるかを seed 17 で比較する。4ブロックの
Q・K・V を置換し、3射影で524,288 Atom、モデル全体で2,097,152 Atom に
そろえる。各条件を4,882更新まで回す。

| 条件 | Q の c | K の c | V の c |
| --- | ---: | ---: | ---: |
| Q に追加 | 128 | 64 | 64 |
| K に追加 | 64 | 128 | 64 |
| V に追加 | 64 | 64 | 128 |

[均等配分のスイープ](lm-qkv-local-sweep-20261117.ja.md)と同じ幅、TinyStories の
分割とデータ順、学習率、スケジュール、GPU 初期化を使う。学習順は V、Q、K。
QKV 以外の Dense 初期値と Atom の個数を照合する。各条件の先頭 Q は独立 CPU
参照と出力・勾配を比較し、CPU 初期化とも照合する。初回 q 更新は実際の
Atom 数で全12射影を確認する。復元後の検証 CE、別ストーリーの確認 CE、
top-1、同期済み更新時間とピークメモリを記録する。

主指標は同じ総予算の3条件の最終検証 CE。以前の seed 17 の均等 c64・c128 は、
異なる総 Atom 数の参考値として使う。1 seed の配置パイロットとする。

均等配分のスイープと同じ torchcst ソースと拡張を使う。同実験のコマンドに
scripts/run_lm_qkv_role_budget.py と新しい OUTPUT を指定する。PAIR_ANCHOR は
前回の幅2048の summary で、再開時は同じ入力と --resume を使う。

## RTX 4090 の結果

seed 17 の3条件が4,882更新を完走し、最終チェックポイントを保存した。
各条件の先頭 Q は CPU・GPU 初期値がビット一致した。独立参照との出力・勾配の
最大相対 L2 誤差は 2.18e-06。各条件の12射影で初回と最終の q 更新を確認した。

| (Q, K, V) | 検証 CE | 確認 CE | 検証 top-1 (%) | 更新中央値 (ms) | ピーク allocated / reserved (GiB) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| (128, 64, 64) | 2.68622 | 2.59546 | 44.57 | 118.48 | 5.752 / 6.115 |
| (64, 128, 64) | 2.74670 | 2.64953 | 43.81 | 118.43 | 5.748 / 6.191 |
| (64, 64, 128) | 2.46447 | 2.39321 | 47.78 | 117.27 | 5.749 / 6.111 |

seed 17 では V を c128 にした配分の検証 CE と確認 CE が最も低かった。
前回の同 seed では、各予算での検証 CE／確認 CE は
全 Dense が 2.43763／2.37238、
均等 c64 が 2.46632／2.39698、
均等 c128 が 3.15618／3.00745 だった。

照合済み集計の SHA-256 は `a08b283b75c0cc52ff668e386bff8a3174c3a5c964a7aabe73985afb8fc5df6a`。
