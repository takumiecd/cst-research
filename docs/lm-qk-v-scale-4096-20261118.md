# Width-4096 follow-up for QK and V placement

English | [日本語](lm-qk-v-scale-4096-20261118.ja.md)

Use the placement selected by the [equal-Atom comparison](lm-qk-v-equal-budget-2048-20261118.md).
Train three arms at seed 17 through update 4,882 on the RTX 4090:
Dense and the selected placement at the earlier two per-role coefficient
settings. Both sets of CST coefficients double the Atom count when width
doubles. The high budget uses 1.5 times the low budget.

Use width 4096 and 16 heads, holding the dimension per head at 256.
Use four blocks, the same frozen TinyStories batches and 1,024 targets
per optimizer update, as well as the earlier rates and schedule. One
sequence per microbatch limits peak activation memory. All arms use that
microbatching. Before training, audit the first Q or V for Y, dX and all
four raw Atom gradients, check the first q update at every CST site, and
measure full-update time and PyTorch allocator peaks for all arms.
Release temporary optimizer state before the final checkpoint restore.

Compare final development and story-disjoint confirmation CE to the
new same-seed Dense arm. Report how the two CE gaps change relative to
the 2048 results for that placement at each budget. Timing and memory
are paired within width. This two-width, one-seed comparison measures
behavior at the two selected budgets.

## Reproduction

Use the same native binary and snapshot as the equal-Atom comparison.
SELECTION contains the verified mean confirmation CE and update time for
both placements and the SHA-256 of the completed BUDGET_SUMMARY. Set
TORCH_EXTENSIONS_DIR to the corresponding SM89 build directory.

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
python scripts/run_lm_qk_v_scale_4096.py --reference-run "$REFERENCE_RUN" \
  --selection "$SELECTION" --budget-summary "$BUDGET_SUMMARY" \
  --source "$SNAPSHOT" --merged-manifest "$MERGED_MANIFEST" --output "$OUTPUT"
~~~

Resume with --resume and the same inputs and output directory.
