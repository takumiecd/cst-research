## 比較モデル

層位置間では同一モデルを使う。

```text
28 -> N1 -> N2 -> N3 -> N4 -> 2
      N1=N2=N3=N4=N, initially1024
```

入力射影と出力headはdenseのまま全層を学習し、4つの隠れ活性化はReLUとする。
3つの正方隠れ変換は全方式でbias無し。全denseに対し、N1->N2（入力寄り）、
N2->N3（中央）、N3->N4（出力寄り）の1層だけをCSTにする3方式を比べる。
幅・深さ・活性化・データ・更新予算を揃える。現在の28->N->N->2とは別モデルで、
複数層の同時CST化は後の別実験とする。

層ごとに独立した初期化乱数系列と共通データ順序を使い、共通の通常層は同一初期値から
始める。同じ幅の置換位置間ではCSTの初期Parameterも共通にする。public初期化を維持し、
活性スケール差を記録してgain校正を暗黙に入れない。公平なLR調整と共通学習期間規則を
用意し、任意の1学習率での失敗を表現力不足の証拠としない。

## 探索と確認の役割

1. **粗い探索。** 同じ深さのdenseが学習できることを先に確認する。例えば各位置で
   alpha={0.0001,0.001,0.01}、seed17から始める。これは計画候補であり、現在の実験と
   短い正しさ/予算pilotの後に実際のgrid・予算を定める。全試行と全曲線を残す。
2. **観測された境界を絞る。** 必要な付近に0.0002/0.0005や0.002/0.005等を追加する。
   最小点でも十分なら境界未到達と報告し、定めた予算内で下へ伸ばす。重要な非単調・
   遷移点を再確認し、精度の単調性を仮定しない。非劣性の未確定を劣性の証明としない。
3. **明示的な仮説を立てる。** A一定、N比例、位置ごとのc*N^p等を候補とし、次の検証前に
   fit入力と予測を保存する。同じNでのc=A/Nは単なる表記変更でありスケール則を識別
   できない。2つの幅だけで指数を確定しない。
4. **独立した予測検証。** 新しい比較群・許容差・LR/checkpoint/期間規則・新seed番号・
   評価分割・解析を採点前に固定する。予測Aとその上下を、新seedとfitに使っていない幅で
   試す。例えば1024の後に2048、1024/2048の後に4096。新seedは再現性、新しい幅は
   外挿予測を検証する。成功は検証した範囲の支持であり普遍法則の証明ではない。
   反例があれば仮説を修正し、別の後続phaseで検証する。

品質基準の出発点は既承認のaccuracy絶対値0.002、ROC-AUC0.002とする。
最終的な多重性・seed解析は新しい比較群を覆う必要があり、現在の8構成の検定は適応的な
追加点を覆わない。有限の確認案として、各位置の候補と隣接1点、denseを3対応seedで
比較できる。実際の群は探索後に固定する。部分集合の確認は試した点だけを支持し、
探索grid全体の最小値を確定しない。支持された試験点の最小alphaと隣接する劣性/未確定、
残る境界を報告する。

正方層では、

```math
A=\lfloor\alpha N^2\rfloor,\quad c=A/N,\quad
A_{\mathrm{required},\ell}(N;Q^*)\approx c_\ell N^{p_\ell}.
```

alpha固定はatom数の二次増加、A一定はalpha∝N^-2、Aの線形増加はalpha∝N^-1。
ある幅でc<1でも線形未満の指数を示したことにはならない。現在のproduct型は
W=sum_a amplitude_a*u_a*v_a^Tで、数学的にrank(W)<=min(A,N)。profileは複数siteを
覆えるため、A<Nでも必ずゼロ行/列が出るわけではない。被覆と独立な線形方向は別。
spacing/radius固定では幅とともに相対supportも変わり、主張の適用範囲に含める。

## 計測とデータ

全密度・位置・LR・seedのtrain/development loss、accuracy、AUCを更新数と同期学習秒数の
両方で重ねる。seed別曲線を残し、準備・評価・checkpoint・HPO・process walltimeを別記する。
captureを含むallocator allocated/reserved peakも記録する。同更新数の品質と、事前に定めた
共通品質目標への時間/メモリを比べ、実用比較には有用な小幅dense/CST対照も残す。

初期/層別の活性・勾配スケール、ゼロ/非ゼロ活性、profile被覆、ゼロ行/列を記録し、
near-zero閾値や有効rank診断の定義を定める。B4の活性行列は自明にrank最大4なので、
より大きい固定の計測外development probeか作用素スペクトル診断を使う。
標本上の不活性・厳密support・rankを区別する。診断は機構の手がかりであり因果の証明ではない。

探索はdevelopmentで行う。開始時には現在のconfirmation50kは評価済みになるため、
新seed/study IDでも未使用holdoutには戻らない。正式な主張前に利用履歴を監査し、
未使用の別評価集合とそれを除いてfitする前処理を固定するか、validation再利用の範囲を
明記する。既存の標準化はtraining10.4M全体でfitしているため、そこから新holdoutを作るなら
前処理の来歴も新たに整える。その標準化を維持する場合は特徴の利用履歴を明記する。
公式testは別途固定した最終評価まで開かない。

## 実行前の準備

明示的なtorchcst revisionに対する実装をcst-researchへ作り、現在の実験は維持する。
各位置と深いモデルのY/dX/全atom勾配・optimizer状態・完全step軌跡を独立に検証する。
既存private Graph cohortは元のモデルと密度gridだけを対象とし、新モデル/低密度には
新admissionが必要で、guardを迂回しない。public eagerか別途検証した実験Graphを対照にも
一貫して使う。該当phaseの前にsource/data/runtime hash、資源予算、適応規則を固定する。
実際の割当上限内で共有L4 poolを使い、文書だけで資源承認やrunner検証済みとはしない。
