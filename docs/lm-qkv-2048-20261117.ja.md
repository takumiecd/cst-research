# 幅2048の TinyStories QKV と FP32 半径デコード

[English](lm-qkv-2048-20261117.md) | 日本語

4ブロックの Q・K・V を置換する。全 Dense・QKV c64・QKV c128 を seed
17・23・42 で比較する。各 seed 内で置換射影以外の通常パラメータの初期値を
一致させる。前回と同じ TinyStories の GPT-2 トークンとデータ順 seed 905 で、
1更新1,024ターゲット、4,882更新まで学習する。幅比較と同じ幅2048、8ヘッド、
文脈128、FFN倍率4とする。

| 条件 | 正方射影ごとの Atom 数 | Atom 数／Dense 重み数 |
| --- | ---: | ---: |
| 全 Dense | — | — |
| QKV c64 | 131,072 | 3.125% |
| QKV c128 | 262,144 | 6.25% |

幅比較で幅2048に選ばれた通常の AdamW 基準学習率 0.0001 を全条件で使用する。
振幅・半径比率は前回の QKV の基準学習率 0.0096、19,531更新のスケジュール、
クリップ、指数型下限での初期化を維持する。学習・評価では有理式下限と
研究用 FP32 デコーダを使う。半径範囲は [0.5, 512]、q はゼロから開始し、
tau を1,536更新で0.03から0.003まで動かす。976、2441、4882更新で再開用
チェックポイントを保存する。

9条件を学習する前に両方の Atom 数を検証する。seed 17 の実サイズ1射影で
出力・dX・Atom の4成分の勾配を CPU FP64 の独立した因子計算と照合し、
広い半径と端点も含める。独立コピーのモデルを使って実際の初回更新を行い、
全12射影の q を確認する。学習した各 QKV 条件で初回と最終の q 更新を記録する。
各条件の前に不要なオプティマイザ状態を回収し、GPU の allocated を記録する。

主指標は8,192ターゲットの検証 CE のペア差とする。ストーリーを分離した
32,768ターゲットの確認 CE と、検証 top-1 も測る。seed ごとに結果を示す。
11更新目以降の同期済み eager 全更新時間と PyTorch のピークメモリを測る。
実行順は seed 17、23、42 の順に Dense/c64/c128、c64/c128/Dense、
c128/Dense/c64 とする。

## 再現方法

[前回の比較](lm-fp32-seed-replication-20261117.ja.md)と同様にソースとデータを固定する。
REFERENCE_RUN にはソースを含む保存済み lm-rational-projection-20261116-02 を
指定する。前回の FP32 スナップショットに、6703a18a55cd949564be8a0ceca1ca1b813f7fc5
からの torchcst QKV 差分を重ねる。結合したマニフェストを指定する。
前回のビルド手順と TORCH_CUDA_ARCH_LIST=8.9 で拡張をビルドし、RTX 4090 で実行する。

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
export TORCH_EXTENSIONS_DIR="$EXTENSIONS"
python scripts/run_lm_qkv_2048.py --reference-run "$REFERENCE_RUN" \
  --source "$SNAPSHOT" --merged-manifest "$MERGED_MANIFEST" --output "$OUTPUT"
~~~

再開時は同じ入力と出力先を使い --resume を追加する。実験登録に結果の保存先を記載する。
