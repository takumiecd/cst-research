# TinyStories の有理式 CST 置換比較

[English](lm-rational-projection-20261116.md) | 日本語

RTX 4090 で全 Dense、FFN down 単独、attention 出力射影単独、QKV 単独を
seed 17 から学習する。幅1024、4ブロック、8ヘッド、文脈長128、FFN倍率4、
1更新あたり1,024ターゲット、4,882更新とする。全条件で元の19,531更新の
学習率スケジュールとデータ順を使う。

| 条件 | 置換射影数 | 射影あたり Atom 数 | Atom 数／置換対象の Dense 重み数 |
| --- | ---: | ---: | ---: |
| 全 Dense | 0 | 0 | — |
| FFN down | 4 | 196,608 | 4.6875% |
| attention 出力 | 4 | 49,152 | 4.6875% |
| QKV c64 | 12 | 65,536 | 6.25% |

保存済み QKV と同様に、各 CST 条件で指数型の半径則でモーメント初期化し、
実行時に有理式へ切り替える。半径範囲は0.5から512とし、下限
(L(a)=0.5+3.5/(1+3(a/0.3)^2)) と上限を従来どおり対数空間で補間する。
半径比率はゼロで初期化し、CSTAdamW で学習する。元の対数空間の tau スケジュール
に従って1,536更新で0.03から0.003まで動かす。新しい各形状で代表1射影の
実サイズ forward と VJP を既存の FP64 因子計算と照合し、タスクの初回更新で
各条件の4射影すべての半径比率を点検する。

主指標は4,882更新時点の検証 CE（8,192ターゲット）とする。最終チェックポイントを
復元し、ストーリーが分離された確認データ（32,768ターゲット）も評価する。
最初の10更新より後の同期済み学習ステップ時間の中央値と、Torch のピーク
allocated／reserved を条件ごとに記録する。各条件は1シードで実行する。

実験登録に記載したソースとデータの manifest を使用する。保存済み有理式 QKV の
ランタイムを隔離ディレクトリにコピーし、torchcst のコミット
`31f40e64241eb866e95305401b94cc8da4ac5a7e` とその親の差分を適用する。
差分は CUDA の形状許可に関する2ファイルを変更する。保存済み `cst-research` の
ソースもランタイムと並べて `source/` に置く。PyTorch 2.9.1+cu128 と
RTX 4090 の実行環境を使う。

```sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/cst-research/src"
python scripts/run_lm_rational_projection.py \
  --archive-root "$ARCHIVES" --source "$SNAPSHOT" --output "$OUTPUT"
```

runner は入力ファイルと元の2条件の初期値ハッシュを検証する。中断した場合は
同じコマンドに `--resume` を付けると、最後に記録されたチェックポイントを
検証して復元する。

## RTX 4090 での結果

全4条件が4,882更新を完走し、復元したチェックポイントで検証結果が再現した。
全 Dense と QKV の検証 CE は保存済みの実験と完全に一致した。QKV の最終
パラメータハッシュも一致した。

| 条件 | 検証 CE | 対 Dense 差 | 確認 CE | ステップ中央値（ms） | ピーク allocated／reserved（GiB） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全 Dense | 2.51733 | 0 | 2.44804 | 36.7 | 4.967 / 5.338 |
| FFN down | 2.49768 | −0.01965 | 2.43741 | 1,402.0 | 5.884 / 6.021 |
| attention 出力 | 2.52955 | +0.01222 | 2.45108 | 376.8 | 3.013 / 4.016 |
| QKV c64 | 2.48323 | −0.03410 | 2.40701 | 1,352.3 | 3.875 / 4.588 |

実サイズの FP64 参照と比較した Y、dX、Atom の4列の勾配で、最大相対 L2
誤差は down が3.35e-7、O が3.20e-7だった。タスクの初回更新では down の
786,432 Atom 中392,993、O の196,608 Atom 中98,580で q が正になり、全置換
射影で更新を確認した。初回試行は down の検査に通過した後、CSTAdamW を接続済み
のモデルを復元しようとして停止した。完走した試行では検査用のモデルを別にコピーし、
全条件をステップ0から学習した。

完走した証拠の保存先は `lm-rational-projection-20261116-02`。取得した結果、
全4曲線、最終チェックポイントのハッシュを照合した。チェックポイントは学習
ホストに保全した。結果のハッシュと中断した実行の保存先は実験登録を参照。
