# 幅2048の QKV と FFN down の併用比較

[English](lm-qkv-down-2048-20261118.md) | 日本語

同じ RTX 4090 で、全 Dense・QKV 単独・FFN down 単独・QKV と FFN down の併用を
seed 17 で比較する。[V 配分比較](lm-qkv-v-allocation-20261117.ja.md)と同じ構成、
4,882更新、凍結した TinyStories の分割、バッチ順、オプティマイザと学習率の
スケジュール、FP32 半径デコード、GPU 分散初期化を使う。4ブロックすべてで置換する。

| 条件 | Q/K/V の係数 | down 射影あたりの Atom 数 |
| --- | --- | ---: |
| 全 Dense | — | — |
| QKV 単独 | 48 / 48 / 64 | — |
| FFN down 単独 | — | 393,216 |
| QKV と FFN down の併用 | 48 / 48 / 64 | 393,216 |

FFN down は8,192入力から2,048出力へ射影する。係数は[幅1024の追試](lm-fp32-seed-replication-20261117.ja.md)
と同じ96で、Atom 数は196,608から2倍になる。各 seed の共通 Dense 初期値を前回の
幅2048比較と照合し、QKV 単独の初期値を V 配分比較と照合する。単独と併用で共通する
射影の Atom 初期値も照合する。

学習前に、各置換条件の先頭射影で出力・入力勾配・Atom の4勾配を独立 FP64 参照と
比較する。FFN down 単独では長方形の射影を検証する。先頭の down の GPU 初期値を
CPU 初期値と照合し、全置換射影で初回の q 更新を確認する。seed 17 の初期状態を
条件ごとに別々にコピーして10更新ウォームアップし、同期した全更新を24回計測する。
更新中央値と PyTorch のピーク allocated・reserved を記録する。

条件別に最終の検証 CE、別ストーリーでの確認 CE、更新時間、アロケータピークを報告する。
seed 17 では、併用条件と同等以上の確認 CE・更新時間を両方達成し、少なくとも一方で
併用を上回る条件があれば、その結果をもとに判断する。該当する条件がなければ
seed 23・42 で4条件を追試する。判定には測定の点推定を使う。

## 再現方法

登録済みの torchcst マニフェストに従い、幅2048のソースに変更を重ねる。
SM89 向けの幅拡張をビルドして TORCH_EXTENSIONS_DIR を指定する。
PAIR_ANCHOR は完了済みの幅2048 c64/c128 の集計、QKV_ANCHOR は完了済みの V 配分の
集計を指す。各段階で別々の出力先を使う。

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
python scripts/run_lm_qkv_down_2048.py --reference-run "$REFERENCE_RUN" \
  --paired-anchor "$PAIR_ANCHOR" --qkv-anchor "$QKV_ANCHOR" \
  --source "$SNAPSHOT" --merged-manifest "$MERGED_MANIFEST" \
  --output "$OUTPUT" --phase pilot
~~~

seed 23・42 の追試は --phase replication を指定する。再開時は同じ入力と出力先に
--resume を追加する。

## RTX 4090 の結果

幅2048の down は独立参照との出力・勾配の照合を通過し、最大相対 L2 誤差は
1.74e-06 だった。先頭 down の GPU 初期値は CPU とビット一致した。
初回の q 更新は QKV の12射影、down の4射影、併用の16射影で通過した。
メモリはアロケータのピーク allocated と reserved を記録した。タイル境界の
CUDA 回帰テスト12ケースも同じ RTX 4090 で通過した。

| 条件 | 事前計測の更新中央値 (ms) | ピーク allocated / reserved (GiB) |
| --- | ---: | ---: |
| 全 Dense | 96.42 | 5.756 / 6.223 |
| QKV 単独 | 117.66 | 5.617 / 6.062 |
| down 単独 | 129.67 | 5.535 / 5.957 |
| QKV ＋ down | 150.58 | 5.400 / 5.650 |

以下の条件は4,882更新に到達し、全学習ログと最終チェックポイントの照合を通過した。
全置換射影の初回・最終 q 更新とオプティマイザ状態も確認した。

低く更新時間も短かった。結果は seed 17 の予備比較を示す。
