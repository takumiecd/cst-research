# 幅2048の Q・K 単独と V 単独の CST 置換

[English](lm-qk-v-partial-2048-20261118.md) | 日本語

同じ RTX 4090 で、seed 17 の2条件を4,882更新まで学習する。全4ブロックで
Q・K 単独は Q・K を c48 で置換し、Atom は合計786,432。V 単独は V を c64 で
置換し、Atom は合計524,288。他の射影は Dense。QKV の Dense 部分には元の重みと
バイアスをコピーし、ビット一致を確認する。CST の初期 Atom は QKV 全置換条件の
対応する射影の初期ハッシュと照合する。

[幅2048の比較](lm-qkv-down-2048-20261118.ja.md)の保存済み全 Dense、QKV 全置換
(48, 48, 64) の seed 17 を対照とする。同じ拡張バイナリ、モデル、TinyStories の
分割、バッチ順、FP32 半径デコード、GPU 初期化とオプティマイザを使う。学習前に
先頭の Q または V の出力・入力勾配・Atom の4勾配を独立参照と照合し、
全置換射影で初回 q 更新を確認する。

検証 CE、別ストーリーでの確認 CE、10更新後からの同期した全更新時間の中央値、
PyTorch のピーク allocated・reserved を報告する。QKV 全置換の各射影の予算を
引き継ぐ1 seed の配置比較で、2条件の Atom 総数は異なる。

## 再現方法

幅2048比較のソースと SM89 拡張ディレクトリ（TORCH_EXTENSIONS_DIR）を使い、
完了済みの集計を PILOT_SUMMARY に指定する。

~~~sh
export PYTHONPATH="$SNAPSHOT/torchcst/src:$SNAPSHOT/torchcst:$SNAPSHOT/cst-research/src"
python scripts/run_lm_qk_v_partial_2048.py --reference-run "$REFERENCE_RUN" \
  --pilot-summary "$PILOT_SUMMARY" --source "$SNAPSHOT" \
  --merged-manifest "$MERGED_MANIFEST" --output "$OUTPUT"
~~~

再開時は同じ入力と出力先に --resume を追加する。

## seed 23・42 の追試

同じ RTX 4090 ジョブで、全 Dense、QKV 全置換、Q・K 単独、V 単独を
seed 23・42 でそれぞれ4,882更新まで学習する。予備比較と同じ配分、データ順、
幅拡張とオプティマイザを使う。全 Dense と QKV 全置換の初期値を幅比較・配分比較の
集計と照合し、部分置換の初期値を QKV 全置換の対応射影と照合する。
scripts/run_lm_qk_v_partial_replication.py を使い、その2集計を --dense-anchor と
--qkv-anchor に、新しい出力先を OUTPUT に指定する。
